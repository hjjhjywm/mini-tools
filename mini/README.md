# mini

小程序集合。一个程序一个文件夹。

## 约定

- 文件夹名：英文小写 + 连字符，例如 `file-renamer`
- 每个程序自带 `README.md`：用途、用法、依赖
- 不提交密钥、密码或真实数据

## 目录

- [xiangqi](xiangqi/README.md) —— 中国象棋（单文件 HTML，零依赖，含 AI 与残局）
- [twenty-four](twenty-four/README.md) —— 24 点游戏（单文件 HTML，零依赖）
- [gh-lens](gh-lens/README.md) —— GitHub 本地浏览器（Node 零依赖，磁盘缓存 + 重试）

新增程序时，同时在根目录 `README.md` 的索引表里补一行。
