# gh-lens

带磁盘缓存和自动重试的 **GitHub 本地浏览器**。为网络不稳的环境设计：抖的时候用缓存顶上，恢复后自动刷新。

## 解决什么问题

直接开 github.com 或者用命令行 `git`/`curl` 时，一次 TLS 抖动就整页失败。gh-lens 把「取数」和「显示」拆开：

- 取数失败 → **自动重试 4 次**（指数退避 300ms → 4s，带抖动）
- 还是失败 → **回退到上次成功抓取的缓存**，并在界面上明确标注「旧缓存 N 分钟前」以及失败原因
- 缓存还新鲜 → **直接命中，不发网络请求**（重复浏览几乎零延迟）

## 快速开始

双击 **`gh-lens.vbs`** —— 没有黑窗口，浏览器自动打开 http://127.0.0.1:8787

然后在左侧输入 `owner/repo`，或点「我的仓库」里的一项，或点 **发现** 看热门 / 搜仓库。

**三种启动方式：**

| 文件 | 体验 | 什么时候用 |
| --- | --- | --- |
| `gh-lens.vbs` | **无控制台窗口**，后台跑，日志写 `logs\server.log` | 日常用 |
| `install-shortcut.vbs` | 在桌面建一个快捷方式（带图标）；加参数 `startup` 还会放进开机启动 | 想要一个能双击的图标 |
| `serve.cmd` | 保留控制台窗口，能实时看日志，关窗口即停服务 | 排查问题时 |

三个入口都是**幂等**的：已经在跑的时候再点一次，不会报「端口被占用」，只会把浏览器切到那个页面。

停止服务：页面左下角 **「停止服务」** 按钮（`POST /api/shutdown`，只接受本机回环请求）。
不用再翻任务管理器找 node 进程。

> 输入框**聚焦时会全选**已有内容（和浏览器地址栏一样）：直接粘贴新地址就覆盖掉旧的，按 Delete 也能一次清空。已经聚焦时再点进去则是正常的光标定位，方便局部修改。

> 需要 Node.js 22.19+ 或 24+。启动器会先用 PATH 里的 `node`，找不到就用 DSH 自带的运行时。

### 改了文件之后记得重启服务

页面本身每次刷新都会重新拉取（服务端 `Cache-Control: no-store`），但 **`server.mjs` 是启动时加载的**。如果你更新了本目录的代码，而服务还是旧进程，就会出现「按钮点了全都没反应」——典型症状是新增的脚本（比如 `query.mjs`）在旧进程的静态路由里不存在，浏览器里 module `import` 拿到 404，`app.js` 整个不执行。

现在的页面有**启动哨兵**：2.5 秒内 `app.js` 没跑起来，会把原因直接写在正文里，而不是让你对着死按钮猜。看到那条提示就在页面左下角点「停止服务」，再重新双击启动器。

（从 1.1.0 起静态资源按扩展名白名单动态解析，新增 `.js/.mjs/.css/.html` 文件**不用再登记路由**；但改 `server.mjs` 本身仍然要重启。）

## 界面上有什么

第一次打开会先显示一屏**使用说明**（三块界面 + 三步上手），点「知道了」关掉；之后随时点右上角的 **?** 叫回来。

| 区域 | 说明 |
| --- | --- |
| 左栏 | 输入 `owner/repo`（或粘 GitHub 链接）回车打开；「我的仓库」= 账号下按最近更新排序的 50 个；**发现** 找新仓库；**离线快照** 缓存当前仓库；底部「停止服务」关进程 |
| 概览 | stars / forks / issues / 体积 / 语言占比 / 许可证 |
| README | 渲染为可读排版（标题、代码块、列表、表格、链接）。**内联 HTML 会自动降级**：`<div align="center">`、`<img>`、`<a>`、`<br>`、`<sub>` 都会转成正常内容，不会再原样显示标签；相对路径的图片自动补成 `raw.githubusercontent.com` 的地址 |
| 文件 | 逐层浏览目录，点文件看源码。每个条目标了**类型**（目录/文档/配置/锁文件/图片…）和**一句用途说明**（比如 `pnpm-lock.yaml` = 锁文件，不要手改），大小用人读单位，右侧 `↗` 直接去 GitHub |
| Issues / PR / 提交 | 各取最近 30 条，点标题在 GitHub 打开 |
| **发现** | 近期热门 / 话题 / 搜索（见下） |
| 顶栏徽标 | **数据来自网络 / 本地缓存 / 旧缓存**、**N 分钟前抓取**、**搜索额度**与**接口额度**（搜索 30 次/分钟，普通接口 5000 次/小时）。鼠标停在徽标上都有完整说明 |

每个标签页顶部都有一行**本页说明**（这页显示什么、能点什么），不用靠猜。

## 发现（github.com/explore 的替代品）

左侧点 **发现** 进入。因为 `github.com/explore`、`/trending` 这类网页在受限网络里根本加载不出来（15 秒超时），这里全部改用 Search API 近似：

| 入口 | 实际请求 |
| --- | --- |
| 近 7 / 30 / 90 天 | `search/repositories?q=created:>{N天前} stars:>=20&sort={排序}&page={n}` |
| 话题 `#ai` 等 | `search/repositories?q=topic:ai&sort={排序}&page={n}` |
| 搜索框 | `search/repositories?q=<你的关键词>&sort={排序}&page={n}` |

**排序**可以切：`★ 星数` / `⏱ 最近更新` / `⑂ fork`。三种模式共用同一个排序选择，切换后自动回到第 1 页。

**加载更多**：第一屏 25 条，底部「加载更多」按 `full_name` 去重追加下一页；到 1000 条上限（GitHub 搜索的硬上限）或数据取尽时显示「已到末尾」。刻意不做无限滚动——滚动触发会不受控地烧掉 30 次/分钟的搜索额度。

**每行三个按钮**，不用先打开仓库就能操作：

| 按钮 | 作用 |
| --- | --- |
| **打开** | **复制仓库页链接 + 新标签页打开**（一步到位，链接已在剪贴板里，方便贴给别人）。先开窗口再写剪贴板，避免浏览器把弹窗当广告拦掉 |
| 复制 | 只把 `owner/repo` 写进剪贴板（这个格式能直接贴进左上角的输入框） |
| 快照 | 直接对这个仓库 `POST /api/prefetch`，把 7 个关键端点缓存下来（之后断网也能看） |

搜索框支持 GitHub 的搜索语法，例如 `stars:>1000 language:go topic:ai`；`Esc` 清空。
结果里的仓库名**点进去就是站内浏览**（概览 / README / 文件 / issues 全都能直接看），旁边的 `↗` 才跳到 GitHub 网页。

> 搜索接口的限额是 **30 次/分钟**（普通接口 5000 次/小时），所以右上角的配额徽标会区分显示「搜索配额」和「配额」。缓存命中不消耗额度——同一页翻回去看是免费的。

## 离线快照（Snapshot）

打开一个仓库后点左栏的 **离线快照**，会把 7 个关键端点一次性抓进缓存：

```
仓库信息 · README · 根目录 · issues(30) · PR(30) · commits(30) · 语言统计
```

之后**即使完全断网**，这个仓库的概览、README、文件、issues、PR、提交都还能看。

## 缓存与日志

- 缓存位置：本目录下 `.cache/`（每个端点一个 JSON，键是路径的 sha256）
- 新鲜期：默认 5 分钟，可在界面上看到；过期后会重新抓，抓失败了才用旧的
- 清理：直接删 `.cache/` 即可，程序会重建
- 日志：用 `gh-lens.vbs` 无窗口启动时，输出写到 `logs/server.log`（超过 4 MB 自动清空重来）。想实时看就往 `serve.cmd` 走。
- `.cache/` 和 `logs/` 都不会进仓库

## 环境变量

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `GHLENS_PORT` | `8787` | 端口 |
| `GHLENS_TTL_MS` | `300000` | 缓存新鲜期；`0` = 永不过期（纯离线模式） |
| `GHLENS_TIMEOUT` | `12000` | 单次请求超时（毫秒） |
| `GHLENS_API_BASE` | `https://api.github.com` | 上游地址，可指向 GitHub Enterprise 或本地桩服务 |
| `GHLENS_NO_OPEN` | — | 设为任意值则启动时不自动开浏览器 |
| `GHLENS_LOG_FILE` | — | 把日志同时追加到这个文件（`.vbs` 启动器会自动设成 `logs\server.log`） |

```powershell
set GHLENS_TTL_MS=0
set GHLENS_PORT=9000
serve.cmd
```

## 安全

- **只监听 `127.0.0.1`**，局域网内其他设备访问不到
- **token 只在服务端使用**，浏览器拿不到（页面里没有任何凭据）
- 路径白名单：只放行 `repos / user / users / orgs / search / rate_limit / gists / notifications / zen / meta / feeds`，并拒绝 `..`、反斜杠、外部主机——防止被当成开放代理
- 只处理 `GET`（外加两个受限的 `POST`：`/api/prefetch`、`/api/shutdown`）
- `/api/shutdown` 额外校验 `Host` 头必须是回环地址，非本机请求一律 403

token 从 DSH 的 GitHub 连接插件凭据读取：

```
~/.dsh/.dsh-github-connect/auth.json
```

## 测试

```bash
node test.mjs       # 单元测试，不联网（127 项）
node smoke.mjs      # 端到端：真起服务 + 真搜一次 + 重复启动 + 停止服务（38 项）
node ui-smoke.mjs   # 假 DOM 里真执行 app.js，再模拟点按钮（72 项）
```

**`test.mjs` 127 项**，只测纯函数（`core.mjs` + `query.mjs`，不联网、不碰文件）：

- 路径校验 19 项（含 SSRF 攻击面：外部主机、路径上跳、反斜杠、非白名单前缀）
- 缓存键与新鲜度判定
- 退避计算（单调性、上下限）
- 可重试判定（429/5xx/ECONNRESET/ETIMEDOUT vs 401/403/404）
- 错误描述、体积格式化、列表整形
- 日期与搜索查询构造（热门/话题/关键词、分页与条数夹取、特殊字符编码）
- **生成的搜索路径必须能通过服务端白名单**——这条是把前端的拼装和后端的校验钉在一起，防止哪天改了查询串直接 400
- 搜索结果整形、数字压缩（`1234 → 1.2k`，且不会出现 `1000k` 这种）

**`smoke.mjs` 38 项**会起两个实例（占 8799 / 8800 端口）：

1. 静态资源、页面引用的每个脚本/样式是否都能取到、非法路径与路径穿越是否被拒、`.cache/` 是否外泄
2. 真实搜一次热门（要网络 + token），再搜一次确认走缓存
3. **把第二个实例的上游指到死端口**，验证「有缓存 → 返回 `cache-stale` 且数据完整」「没缓存 → 老实 502」
4. **重复启动**（同端口再起一个 → 应识别出已在运行并 exit 0）、**日志落盘**、**`/api/shutdown` 只接受 POST 且能把服务停掉**

**`ui-smoke.mjs` 72 项**塞一套最小 DOM，真的 `import app.js`，然后：

- 检查 `app.js` 能执行完、按钮都绑上了 `onclick`（import 失败会直接抛，这条能挡住「新增脚本没路由」）
- 模拟点「发现」：面板渲染出来、发出了 `search/repositories` 请求、请求带对日期过滤、结果渲染出仓库名/总数/星数、配额徽标正确
- 再点「近 7 天」和 `#rust` 话题，确认查询串跟着变

`query.mjs` 故意不 import 任何东西（连 `node:crypto` 都不碰），所以浏览器能用 `<script type="module">` 直接加载它，Node 侧 `core.mjs` 复用同一个 `shapeRepo`——查询拼装只存在一份，不会前后端两套漂移。

## 限制

- 只读：不能建 issue、不能改文件（需要写操作请用 `github_api` 工具或 GitHub 网页）
- 不做 diff / 代码高亮 / 评论详情
- README 的 Markdown 是**极简渲染**：常见语法和内联 HTML（图片/链接/换行）都能处理，但脚注、mermaid 图、复杂 HTML 表格会退化成纯文本
- 匿名模式下限额很低（每小时 60 次），没有 token 时会很慢

随仓库。
