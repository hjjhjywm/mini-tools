# 中国象棋 · Chinese Chess

一个纯前端、零依赖的中国象棋游戏，**双击 HTML 即可游玩**，无需安装任何运行时。

## 快速开始

双击 `dist/中国象棋.html`，用浏览器打开即可开始。

不需要 Node.js、不需要安装、不需要联网。

## 功能

### 对局

- **人机对战** — 四档难度，可选执红或执黑
- **双人对战** — 两人共用一台电脑轮流下
- **完整规则** — 蹩马腿、塞象眼、炮需炮架、过河兵横走、九宫限制、将帅照面、将死困毙、三次重复判和

### AI 引擎

迭代加深 + Alpha-Beta 剪枝 + 置换表 + 静态吃子搜索 + 杀手着法 + 空着裁剪。

| 难度 | 搜索深度 | 实际表现 | 平均着法损失 |
|---|---|---|---|
| 入门 | 1 层 + 65% 随机 | 会走废棋，新手能赢 | ≈195 分（约一个车） |
| 普通 | 2 层 + 20% 随机 | 会丢子 | ≈74 分（约一个马） |
| 困难 | 5 层 | 要认真对待 | ≈37 分 |
| 大师 | 12 层 | 几乎不犯错 | ≈36 分 |

> 「平均着法损失」用深度 4 搜索作裁判统计，数字越小越强。

### 残局挑战

9 个残局，分入门 / 普通 / 困难 / 大师四档。玩家固定执红先手，限步内将死即通关。卡住了可以看提示。

所有残局都经 AI 实战验证**确实可解**（见 `npm run test:solvable`）。

### 棋局回顾

- 对局结束自动询问是否保存
- 支持导入 `.json` / `.txt` 棋谱
- 逐手前进后退、拖动进度条、自动播放
- 可删除不要的棋局

> 棋谱存在浏览器 localStorage 里，**换浏览器或清缓存会丢失**。重要棋局建议手动导出保存。

### 体验细节

- 木纹棋盘、汉字圆子、楚河汉界
- 棋子平滑滑动（三档速度可调）
- 上一步走子高亮、可走位置提示、被将军红色警示
- 音效：落子、吃子、将军、胜负、操作反馈，音量可调可静音（Web Audio 实时合成，无音频文件）

## 界面操作

| 操作 | 说明 |
|---|---|
| 点击棋子 | 选中，显示可走位置（绿点空格 / 红圈可吃） |
| 点击目标格 | 走子 |
| `U` 键 | 悔棋 |
| `N` 键 | 重新开局 |

## 项目结构

```
chinese-chess/
├── app/
│   ├── engine.js      规则引擎：走法生成、合法性校验、将军判定、终局判定
│   ├── ai.js          搜索：迭代加深 + Alpha-Beta + 置换表 + 评估
│   ├── endgames.js    残局题库
│   ├── replay.js      棋谱存储、导入导出、回放
│   ├── sound.js       音效合成（Web Audio）
│   ├── main.js        界面渲染与交互
│   ├── index.html
│   └── style.css
├── tests/             264 项自动化测试
├── dist/              构建产物（可直接游玩）
│   └── 中国象棋.html
└── build-single.js    把 app/ 内联成单个 HTML
```

## 开发

```bash
# 运行全部测试
npm test

# 重新生成单文件 HTML
npm run build

# 难度曲线评测
npm run test:difficulty

# 残局可解性验证
npm run test:solvable

# AI 自对弈演示
npm run selfplay
```

## 已知限制

- 棋谱存在 localStorage，换浏览器或清缓存会丢失
- AI 的天花板约在业余中高段，打不过专业棋软
- 长将按「三次重复判和」处理，未实现完整的亚洲规则细则
- 未实现中局库 / 开局库
