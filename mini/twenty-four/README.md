# 24 点

用四个数字算出 24 的算数游戏。单文件网页，双击就能玩。

## 玩法

给定四个数字，用 **+ − × ÷** 和括号，让每个数字**各用一次**，结果正好等于 **24**。

```
8 ÷ (3 − 8 ÷ 3) = 24
```

允许中间结果是分数 —— 上面这个经典解就是靠 `8/3` 才成立的。

## 运行

双击 `index.html`，用浏览器打开即可。

- **零依赖**：不需要 Node、不需要联网、不需要装任何东西
- **离线可用**：整个游戏就在一个 HTML 文件里，拷到 U 盘也能玩

## 功能

| 功能 | 说明 |
| --- | --- |
| 难度 | 简单（1–9）/ 标准（1–13） |
| 输入 | 键盘直接输入，或点数字卡片插入，或使用右侧屏幕键盘 |
| **屏幕键盘** | 19 键，**全程只用鼠标即可完成一局** |
| 提交 | 按 **Enter**、点「提交」、或按键盘上的「提交」 |
| 提示 | 显示一个参考答案（本题不计连胜） |
| 统计 | 已解出题数、连胜、本局用时 |

符号兼容：`×` ÷ `*` `/`、全角 `＋－（）`、`x` 和 `X` 都能识别。

## 屏幕键盘

右侧有一块 19 键的屏幕键盘，布局与原文字键盘一致：

```
(    )    ⌫    C
7    8    9    ÷
4    5    6    ×
1    2    3    −
0 (横跨两格)  +    提交
```

- 点数字/运算符/括号 → **插入到光标位置**（先把光标点到想插的地方，不是只能加在末尾）
- `⌫` 删光标前一个字符，`C` 清空
- 右下角「提交」直接判题

宽屏时键盘在右侧，窄屏（< 1040px）自动折到下方。按键为**大号尺寸**（键高 104px、字号 36px），方便纯鼠标/触屏操作。配合界面上的「换一题」「提示」按钮，**整局游戏不需要碰实体键盘**。

## 实现要点

### 必须用精确分数

浮点数在这里会翻车：`8/3` 无法用 double 精确表示，`8/(3-8/3)` 在浮点下会算成 `23.999999999999996`，判等失败。所以全程用**既约分数**（`{n, d}` 整数对）运算，最后判断 `n === 24 * d`。

### 出题保证有解

随机取四个数字后调用求解器验证，无解就重抽。求解器枚举"每次合并两个数"的所有递归组合（加减乘除各一次，除法需排除除零），找到解即返回算式。

### 校验用户输入

不用 `eval`。词法分析 → 递归下降求值，同时收集用到的数字，最后比对：

1. 数字多重集必须与题目完全一致（不能多用、少用、或用题目外的数）
2. 结果必须精确等于 24

因此 `(3+3)*4` 会被拒绝（含题目外的 4），`8*3` 也会被拒绝（少用了两个数）。

## 健壮性

游戏是单页静态页面，没有后端可兜底，所以把能想到的坏情况都在前端消化掉：

| 场景 | 处理方式 |
| --- | --- |
| 超长输入（> 120 字符） | 词法阶段直接拒绝，不让解析器空转 |
| 括号嵌套过深（> 24 层） | 拒绝，避免递归下降把栈打穿 |
| 题目数据异常（不是 4 个数字） | 返回提示而不是抛异常 |
| 畸形输入（`(((((`, `1/0`, `8**3` …） | 全部被捕获为错误消息，页面不崩 |
| 成功瞬间又点「换一题」或切难度 | 挂起的自动换题被取消，不会连跳两题 |
| 事件处理器内部异常 | 被 `safe()` 包裹，显示提示而不是白屏 |
| `localStorage` 不可用（隐私模式） | 静默跳过持久化，游戏照常进行 |
| 粘贴多行文本 | 换行、回车、制表符自动转成空格 |
| 回显用户算式 | 用 `textContent` 构造节点，不走 `innerHTML` |
| 事件目标不是元素节点 | 取用前先判断 `closest` 是否存在 |

已解出题数会存在本地（`localStorage`），刷新不丢；其余状态每局重置。

## 测试

```bash
node test.mjs
```

测试从 `index.html` 中**原样抽取**解题逻辑块再运行，测的就是发布出去的那份代码，不存在副本漂移。

覆盖 **50 项**，包括：

- 整份内联脚本的语法可解析性
- 分数运算的边界（除零、负分母归一化）
- 7 道经典题的可解性判定
- **对 1–6 全部 1296 组数字，与一个独立的括号模式枚举求解器交叉比对**（结果 100% 一致）
- 300 局随机题生成的解，全部能通过自己的校验器
- 13 条负例（多余数字、少用数字、除以零、括号不匹配、非法字符等）
- 9 条健壮性用例（超长输入、30 层括号、10 层括号仍可用、`nums` 异常、生成器参数倒置、10 组畸形输入不抛异常）
- 7 条屏幕键盘用例（HTML 标签配对、按键数量、数字 0–9 齐全、**每个输入键都能被词法器识别**、功能键齐全）
