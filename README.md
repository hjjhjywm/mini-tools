# DSH 小程序集

用 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）写的小工具，一个程序一个文件夹。
**每个程序都能独立运行，不需要装 dsh 本体。**

## 目录

| 程序 | 是什么 | 怎么运行 | 依赖 |
| --- | --- | --- | --- |
| [xiangqi](mini/xiangqi/) | 中国象棋：人机对战 / 双人 / 残局挑战 / 棋局回顾，四档 AI 难度 | 双击 `dist/中国象棋.html` | 无 |
| [twenty-four](mini/twenty-four/) | 24 点游戏：四个数字算出 24，带可纯鼠标操作的屏幕键盘 | 双击 `index.html` | 无 |

## mini/xiangqi — 中国象棋

纯前端零依赖，单文件 HTML（101 KB），双击就能玩。全套 264 项自动化测试。

**玩法**

- **人机对战** — 四档难度：入门 / 普通 / 困难 / 大师，可选执红或执黑
- **双人对战** — 两人共用一台电脑轮流下
- **残局挑战** — 9 个残局分四档，限步内将死即通关，带提示
- **棋局回顾** — 保存 / 导入棋谱、逐手回放、自动播放、删除

**规则与引擎**

- 完整规则：蹩马腿、塞象眼、炮需炮架、过河兵横走、九宫限制、将帅照面、将死困毙、三次重复判和
- AI：迭代加深 + Alpha-Beta 剪枝 + 置换表 + 静态吃子搜索 + 杀手着法 + 空着裁剪
- 难度实测（用深度 4 搜索作裁判统计平均着法损失）：

  | 难度 | 搜索深度 | 平均损失 |
  | --- | --- | --- |
  | 入门 | 1 层 + 65% 随机 | ≈195 分（约一个车） |
  | 普通 | 2 层 + 20% 随机 | ≈74 分（约一个马） |
  | 困难 | 5 层 | ≈37 分 |
  | 大师 | 12 层 | ≈36 分 |

**体验细节**：木纹棋盘、汉字圆子、棋子滑动（三档速度）、可走位置提示、被将军警示、音效（Web Audio 实时合成，可调音量 / 静音）。

```bash
cd mini/xiangqi
npm test                  # 264 项测试
npm run build             # 重新生成单文件 HTML
npm run test:difficulty   # 难度曲线评测
npm run test:solvable     # 残局可解性验证
```

细节见 [mini/xiangqi/README.md](mini/xiangqi/README.md)。

## mini/twenty-four — 24 点游戏

单文件 HTML（31 KB），零依赖，双击就能玩。

- **保证有解**：出题时先随机求解，解不出来就重出，不会给你一盘死局
- **屏幕键盘**：整局可以只用鼠标完成，键盘按钮是普通的两倍大，按光标位置插入
- 撤销 / 重来 / 提示 / 难度切换

62 项测试（含 1296 组算式的交叉验证）：`node test.mjs`

## mini/gh-lens — GitHub 本地浏览器

打开 GitHub 时一次 TLS 抖动就整页失败，这个工具把「取数」和「显示」拆开：

- 取数失败 → **自动重试 4 次**（指数退避 300ms → 4s，带抖动）
- 还是失败 → **回退到上次成功的缓存**，并在界面上标注「旧缓存 N 分钟前」以及失败原因
- 缓存还新鲜 → **直接命中，不发网络请求**

除了浏览，还有：

- **发现**：近期热门 / 话题 / 仓库搜索（全部走 Search API，因为 `github.com/explore` 在受限网络里加载不出来），支持排序切换、翻页、每行一键快照
- **Snapshot**：把一个仓库的 7 个关键端点一次性缓存，之后断网也能看
- 无控制台窗口启动（`gh-lens.vbs`）、桌面快捷方式、页面内一键停止服务

```bash
node test.mjs      # 108 项：纯函数，不联网
node smoke.mjs     #  38 项：真起服务、真搜一次、缓存回退、重复启动、停止服务
node ui-smoke.mjs  #  46 项：假 DOM 里真执行 app.js，再模拟点按钮
```

细节（环境变量、缓存位置、安全边界、限制）见 [mini/gh-lens/README.md](mini/gh-lens/README.md)。

## 约定

- 一个程序一个文件夹，各自带 `README.md`（用途 / 用法 / 依赖）
- **不提交密钥、令牌或真实数据**：gh-lens 的 token 在运行时从本机凭据文件读取，仓库里没有
- 测试脚本跟程序放在一起，命令写在各自的 README 里
- 直接提交到 `main`
